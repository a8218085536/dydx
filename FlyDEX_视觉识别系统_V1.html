标识 · 深度之蝶 The Depth Butterfly

Logo 的创意来自交易所最核心的图形——订单簿深度图。买盘与卖盘的深度阶梯左右对称展开，天然构成一对蝶翼：左翼为买盘（蝶翼绿），右翼为卖盘（深林绿），蝶身是价格轴。看懂交易的人一眼看到订单簿，看不懂的人一眼看到蝴蝶——一个图形，两层阅读。四级透明度递减的翼片同时隐喻流动性深度与「万蝶成海」的汇聚。

4

吉祥物 · 蝶宝 EDDY

EDDY（蝶宝）= EDEX 的 AI Agent 具象化。设定：一只圆头圆脑的机械蝶，翅膀即深度图（与 Logo 同构），触角是天线——它 7×24 替你盯盘做市。EDDY 出现的地方就代表「你的 Agent 正在工作」：做市中、涨跌播报、成就庆祝、风险提醒，都由 EDDY 出面，让冷冰冰的交易所有一个可以喜欢的角色。

🟢

做市中

双翼匀速轻扇 · 眼睛为「—」专注线，用于 Agent 视图工作状态

📈

上涨播报

左翼（绿）展开变大 · 眼睛为「↑」，用于行情推送与涨幅海报

🎉

释放到账

头顶撒出绿色翼片粒子，用于每日额度释放与成就页

🛡️

风险提醒

双翼收拢呈盾形 · 眼睛为「!」，用于风控提示与安全教育

命名：中文「蝶宝」，英文「EDDY」（取自 EDEX，发音亲切）。使用纪律：EDDY 只出现在运营/社区/教育场景与 Agent 视图；专业交易界面（Pro 盘口、K 线）不出现吉祥物，保持专业感。

4.1 母舰彩蛋 · 「飞碟起飞，万蝶出舱」

「飞蝶」读音即「飞碟」——这个梗要用足。设定一艘 EDEX 母舰飞碟：舱门打开，成群的蝴蝶机器人（EDDY 蝶群）从飞碟里飞出，散向市场开始做市。用于开屏动画分镜、表情包、活动 KV 与社区梗图；一句话文案固定为「飞碟起飞 · 万蝶出舱」。

🛸
